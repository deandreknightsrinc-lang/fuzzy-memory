# fuzzy-memory

- [`church/`](church/) - the BAC Ministries church home and the free white-label church platform for other churches, with the Bible: dramatized audio Bible, cinematic Bible, many versions and the extra books (see its README)
- [`studio-desk/`](studio-desk/) - Studio Road Case Desk: an interactive template for an L-shaped studio desk built from two flight cases (laminated cardboard or plywood, faux-leather finish, cut lists, shopping list, desk ↔ road case conversion)
- [`dashboard/`](dashboard/) - artist dashboard
- [`kbk-studio/`](kbk-studio/) - KBK Studio: 16 sample pads you play from a MIDI keyboard, a URL reader (links to audio files, with an optional helper for YouTube/SoundCloud), stem split, and an audio/video file converter
- [`kbk-studio-plugin/`](kbk-studio-plugin/) - KBK Studio 2: the Logic Pro plug-in (AU, VST3, standalone). 16 pads that auto-chop songs and loops across the pads, links via the KBK helper, Neural Tone (NAM amp captures), AI Vox (RVC voice conversion), glue comp, tape and limiter
- [`knight-keys/`](knight-keys/) - Knight Keys, a browser-based MIDI learning studio (see its README)
- [`knight-lyfe-ultimate/`](knight-lyfe-ultimate/) - Knight Lyfe Ultimate: Knight Keys as a Logic Pro plug-in (AU), VST3 and standalone app
- [`sound-library/`](sound-library/) - Knight Lyfe Sound Library: build an organized sound library on a drive, link it into Logic Pro, and sort new samples automatically
- [`ai-studio/`](ai-studio/) - Knight Lyfe AI Studio: one-command setup of local AI agents (mix, sound design, producer), stem splitting, auto-mastering and lyrics on a home server
