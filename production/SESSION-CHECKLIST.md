# W.O.M.P. Session Checklist and Tracker
Run every song through these stages in order. Tick them off in the tracker at the bottom, so we always know where each
song stands across both albums.

## Stage 1: Suno Discovery
- [ ] Paste the **Style** prompt and the **Exclude Styles** list from the song file. Use Custom mode and paste the lyrics.
- [ ] Set Weirdness to 35–45% and Style Influence to 65–75%. Use the Knight Persona once it's locked.
- [ ] Generate 4 takes. Score each 1–5 on **Pocket / Low End / Hook melody / Vocal tone / Story clarity**.
- [ ] Keep the best take. Write down what drifted, and adjust the prompt with me before the next round.
- [ ] Export stems (Suno), or plan to use Logic's Stem Splitter.

## Stage 2: Logic Setup
- [ ] Use the "WOMP Template" project (see below). Set the BPM and key from the take.
- [ ] Import stems. Run Smart Tempo if needed, and check the downbeat alignment.
- [ ] Put each stem on its own track, color-coded: drums red, bass purple, keys and samples gold, gospel white, vocals blue.

## Stage 3: Rebuild the Weapons
- [ ] **Drums:** program DMD layers (kick, snare+clap, hats, perc). Run WOMP Pocket on them. Blend the Suno drums underneath, or mute them.
- [ ] **808:** transcribe the bass into MIDI, then play it with the 808 patch through WOMP 808 Glide. Put WOMP Low End on the channel.
- [ ] **Synth/live bass:** add the body lane (HPF at 70 Hz). Sidechain it to the kick.
- [ ] **Keys and samples:** replay on Vintage EP, B3, or Clav with WOMP Soul Chords, or keep the Suno keys through WOMP Dust.
- [ ] **Signature layer:** whistle lead (WOMP Whistle), talkbox, horn stabs, or strings, as the song notes say.
- [ ] **Gospel layer:** organ swells, choir stacks, tambourine.
- [ ] **Arrangement:** follow the song's arrangement map. Add drops before hooks, and a new element on each hook return.

## Stage 4: Vocals
- [ ] Record Knight's lead over the rebuilt beat, using the Suno vocal as a muted guide.
- [ ] Punch in doubles on bar endings, and record ad-libs on a separate track.
- [ ] Hazel/feature vocals: record them, then stack the harmonies (3rd above, 5th below).
- [ ] Comp. Use Flex Pitch on long notes only.

## Stage 5: Mix
- [ ] Gain-stage everything to peak around −18 dBFS pre-fader. Aim for about −6 dBFS peaks on the Stereo Out.
- [ ] Set up the drum bus, the parallel crush, the vocal chain, and the sends (plate, delay, hall).
- [ ] **Low-end check:** listen on phone speakers, a car, and headphones. Solo the kick and 808 and check they're in tune.
- [ ] A/B against references at matched loudness.

## Stage 6: Master and Deliver
- [ ] Master to −8.5 to −7.5 LUFS integrated (Uptempo 808 Mode). True peak −1.0 dBTP.
- [ ] Bounce: 24-bit WAV master, instrumental, a cappella, TV track (the beat plus the hooks), and clean edits.
- [ ] Metadata: ISRC, credits, splits. Register with your PRO and The MLC.

## The "WOMP Template" (build it once in Logic, then File → Save as Template)
| Track | Instrument / FX |
|---|---|
| DRUMS (DMD) | WOMP Pocket → WOMP Rolls (MIDI FX) → DMD kit → routed to DRUM BUS |
| 808 | WOMP 808 Glide → WOMP Rolls (Single Note) → Sampler 808 → WOMP Low End (Drive 45–70%) |
| SYNTH BASS | Retro Synth "funk mono" → Channel EQ HPF 120 Hz (the 808 owns the sub) |
| RHODES | WOMP Soul Chords → Vintage Electric Piano → WOMP Dust |
| B3 | WOMP Soul Chords → Vintage B3 |
| WHISTLE | WOMP Whistle → Retro Synth sine → Tape Delay |
| TALKBOX | Vocoder Synth |
| STRINGS / HORNS | Studio Strings / Studio Horns |
| CHOIR | Audio stacks → CHOIR BUS (hall) |
| VOX LEAD / DBL / ADLIB / HAZEL | The vocal chains from the Sound Guide §4 |
| Aux buses | DRUM BUS, CRUSH, PLATE, DELAY 1/4, HALL, CHOIR BUS |
| Stereo Out | Mix-bus chain (Sound Guide §5) |
