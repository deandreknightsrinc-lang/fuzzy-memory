    Audio

    What links work

    • Direct audio files (.wav .mp3 .aif .flac .ogg .m4a): read right in the browser when the site allows it.
    • Dropbox, Google Drive, OneDrive, GitHub share links: changed to the direct file for you.
    • YouTube, SoundCloud, TikTok, Instagram, Vimeo, Bandcamp and sites that block reading: need the KBK helper running.
    • Spotify, Apple Music, Tidal lock their audio and can't be read.
    • Only pull audio you own or have the rights to use.

    MIDI keyboard

    Last message: —

    • Pads: 16 keys from the pad-1 note play the pads (pad controllers usually start at C1 = 36).
    • Keys: the whole keyboard plays the selected pad up and down in pitch. C3 (middle C) is its own pitch.
    • Split: pads on the lowest 16 keys, the selected pad on every key above.
    • Sustain pedal holds Hold/Loop pads, pitch bend bends them, the volume knob (CC 7) sets the master.
    • Computer keys work too: 1 2 3 4 / Q W E R / A S D F / Z X C V, Space stops all.

    KBK helper

    A small program for your Mac or studio server that does what a browser can't: read YouTube/SoundCloud and sites that block reading, Demucs stems, and FLAC/M4A/OGG files.

    Start it on your Mac

    cd ~/fuzzy-memory/kbk-studio/server
bash setup-helper.sh      # once: yt-dlp + ffmpeg (add --stems for Demucs)
bash start-helper.sh      # then open http://localhost:8765
