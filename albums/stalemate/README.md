# STALEMATE by King Bishop Knight
*A 20-track chess-themed storytelling hip-hop album. First draft. See `../PROJECT-BIBLE.md` for the world and characters.*

*Produced to the W.O.M.P. sound (`../../production/WOMP-SOUND-GUIDE.md`). BPM and key per track are below; "half-time" cuts are written at the listed tempo but feel like half of it. Each song file has its Suno style prompt, Exclude Styles and Logic Pro production notes.*
